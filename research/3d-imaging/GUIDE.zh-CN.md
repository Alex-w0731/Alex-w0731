# 三维科研成像 workflow 使用指南

核查日期：**2026-10-02**。适用于共聚焦、光片和其他具有真实 z-stack 的显微科研数据。项目与条款见 [SOURCES.md](SOURCES.md)。

**浏览器当前提供流程规划与合成演示，没有真实 AI 推理后台。** 页面中的参数变化、合成细胞、三维模型或状态反馈用于理解流程，不表示已读取你的显微文件、执行 Cellpose、完成拼接或产生有效测量。真实分析需在下述外部工具中运行，并将结果与记录保存。

## 先明确数据和问题

可回答的研究问题示例：在经实验确认的肿瘤区域，某类免疫细胞与肿瘤细胞、血管或组织边界的三维空间分布有何差异？处理组与对照组在细胞密度、形态和距离分布上是否存在可重复差异？

输入应包含体数据、采集元数据和实验设计。只有二维切片时，可进行二维分析；沿 z 复制、插值或用模型补全后显示为三维，不会增加真实深度证据。CT/MRI 的坐标、器官分割及验证另需专门方案，本指南不把 Cellpose 作为通用医学模型。

## 步骤 1：核对轴、尺度与通道

先在 Fiji 或 napari 检查一小段数据，记录以下信息，确认后再批处理：

| 字段 | 要填写的内容 | 常见错误 |
|---|---|---|
| `axes` 与 `shape` | 明确 t、c、z、y、x 各轴及长度。OME-Zarr 可用 `t,c,z,y,x`，没有的维度也需明确；不同工具的期望顺序不相同。 | 把通道当成 z，把时间当成深度，仅凭长度自动猜轴。 |
| `spacing` / voxel size | `dz, dy, dx` 与单位，来自采集记录或可核查校准。 | 默认所有方向 1 µm；把像素尺寸与光学分辨率混为一谈。 |
| `channel` | 每个通道的名称、染色/标记、用途、曝光等，注明分割通道和表型判定通道。 | RGB 展示颜色等同于原始通道；某标记阳性直接当作已证明的细胞身份。 |
| `PSF` | 有无实测或理论点扩散函数、对应通道/视图、采集条件和文件版本。 | 用不匹配的 PSF 反卷积；把任意锐化称为真实恢复。 |
| `anisotropy` | 在 dx≈dy 时，Cellpose 的 z/xy 采样比可记为 `dz/dy`。 | 在未确认轴和 spacing 时填写数值；插值后仍沿用原来的间距。 |
| 坐标与位深 | 原点、方向、变换、像素类型、强度范围、时间间隔和缺失层。 | 改强度位深却不记录；拼接后丢失坐标；缺失层被悄悄填补。 |

例如：`axes = z,c,y,x`，`shape = 80,4,512,512`，空间间距 `dz = 1.0 µm`、`dy = dx = 0.25 µm`，对应各向异性比为 4。这个数值说明采样差异，不能证明轴向分辨率已达到横向水平。若 dx 与 dy 不同，应先确定各工具怎样处理该情况并验证坐标转换。

Cellpose 当前官方文档允许显式指定 `z_axis`、`channel_axis` 和 `anisotropy`；避免依赖自动猜测。[3D 输入与参数](https://github.com/MouseLand/cellpose/blob/main/docs/do3d.rst)。

## 步骤 2：建立多尺度数据层

保留原始采集文件为只读版本，派生数据另存。用 [OME-Zarr 官方文档](https://ome-zarr.readthedocs.io/en/stable/) 与 [writer 说明](https://github.com/ome/ome-zarr-py/blob/master/ome_zarr/writer.py) 组织分块数据与多尺度金字塔，显式写入 axes、scale、units 与坐标变换。

对科研图像按任务选择下采样；实例标签需要保持离散 ID，不能对标签做线性插值。记录每个尺度的实际 spacing。完成后抽查原始与重读文件的形状、位深、通道、数值与物理位置，确认单位不会在转换中丢失。

先用小 ROI 测试块尺寸和内存，再扩大数据范围。全局三维使用低分辨率概览，ROI 精查读取原始分辨率，定量依据使用完整测量层。napari 当前 stable 文档的三维多尺度显示只呈现最低分辨率级别，不应将它解释为原生全细节流式三维。[napari Image](https://napari.org/stable/howtos/layers/image.html)。

## 步骤 3：按需要拼接、配准和预处理

单体数据跳过拼接。多 tile 或多角度数据采用下面的一条支路：

1. **Fiji / BigStitcher**：按[官方安装与流程](https://imagej.net/plugins/bigstitcher/)启用更新站点，定义 dataset，核对通道、视图、时间与初始位置，保存 XML。完成 pairwise shift、预览与过滤、global optimization，检查接缝和对应点，再输出融合体数据。需要放大计算时参考 [BigStitcher-Spark](https://github.com/JaneliaSciComp/BigStitcher-Spark)，逐步回到 GUI 验证。
2. **Python / multiview-stitcher**：从[官方 quickstart](https://github.com/multiview-stitcher/multiview-stitcher)加载小型测试数据，保留 stage metadata 的变换键，另存 registration 变换键；查看注册摘要，对照前后，再执行分块融合。使用与你锁定版本匹配的官方示例，不将目前尚不支持的非刚性变换写成已可用。

检查不同通道是否存在空间错位、边缘亮度差异、重复结构或漏块。记录配准残差及剔除依据；没有足够重叠或可靠对应点时，补采或人工处理，不让漂亮的融合图掩盖不可靠对齐。

平场/背景校正、去噪或反卷积均作为明确的派生步骤。反卷积需匹配 PSF；可用 BigStitcher 的[PSF 管理流程](https://imagej.net/plugins/bigstitcher/psf)从合适的荧光微珠估计或分配 PSF。没有可信 PSF 时可跳过反卷积，并记录原因。对照处理前后的信号和分割表现，保留所有参数及原始数据。

## 步骤 4：候选分割，先 ROI 后全体

按照 [Cellpose 官方安装说明](https://github.com/MouseLand/cellpose)建立独立环境，记录软件版本、模型名称、权重来源和摘要。已在官方文档核实的 GUI 启动方式是：

```text
python -m pip install "cellpose[gui]"
python -m cellpose --Zstack
```

先选择覆盖高密度、稀疏、低对比、组织边界、深层和拼接接缝的代表性 ROI；核对 axes、分割通道及 anisotropy。对照 XY/XZ/YZ 视图检查标签，再决定是否扩大推理。Cellpose 默认三维方案在正交二维切片计算预测并在三维运行 dynamics；不要仅因输出三维标签就假设各向异性已被正确处理。[官方 3D 说明](https://github.com/MouseLand/cellpose/blob/main/docs/do3d.rst)。

较大数据参考[分布式 Cellpose](https://github.com/MouseLand/cellpose/blob/main/docs/distributed.rst)：Zarr 输入、重叠块推理和标签合并，通过 Python API 运行。检查块边缘是否发生跨块细胞重复计数或断裂。具体 API 与参数以锁定版本的官方示例为准，不从浏览器配置推断一条未验证的运行命令。

细胞核分割不能直接替代完整细胞边界；细胞实例分割也不能自动决定肿瘤、免疫或其他表型。根据实验标记、阴性/阳性对照及预先定义的规则给对象表赋予表型。

## 步骤 5：人工 ROI 复核与 QC 关卡

在 [napari](https://github.com/napari/napari)同时查看原图、预处理图、自动标签和最终标签。原始分辨率 ROI 中人工检查漏检、粘连、碎裂、误分割、通道错位及块边界；编辑保存为新标签版本，记录修改对象与复核者。标签编辑使用二维切片视图；必要时设置跨邻近切片的笔刷范围。三维显示及多尺度标签不可直接编辑。[Labels 文档](https://napari.org/stable/howtos/layers/labels.html)。

| 关卡 | 检查方式 | 未通过时的处理 |
|---|---|---|
| 元数据 | 轴顺序、spacing、单位、channel、缺失层与原记录一致。 | 补齐或修正记录，停止单位相关测量。 |
| 配准 | 接缝、已知结构、对应点残差及跨通道位置检查。 | 重配准、限制分析区域或补采。 |
| 图像质量 | 饱和、低对比、深度衰减、遮挡、处理伪影。 | 记录排除/分层规则；重新选择采集或预处理条件。 |
| 分割 | 代表性 ROI 的人工标注对照；对象级漏检/重复、边界、碎裂与粘连。 | 调参、微调或修正；重新检查独立验证 ROI。 |
| 三维与尺度 | 在正交切片核对完整性；检查下采样/插值与 anisotropy。 | 重新设置尺度或限制可解释的指标。 |
| 输出 | 标签、对象表、坐标与导出文件相互对应，重读可恢复。 | 修复导出与 ID 映射，再发布结果。 |

有人工参考标签时，可记录 Dice/IoU 与对象级检测错误，但必须说明对象匹配规则、样本数和 ROI 选择。无参考标注时，只报告人工抽检及已知失败模式；不将模型分数写成已校准的正确概率。QC 阈值在实际验证样本上预先确定，不从合成演示中推导。

## 步骤 6：标签定量，网格呈现

**Labels** 是每个体素的离散类别或实例 ID，适合计数、体素体积、原始强度关联与实例复核。**Mesh** 是从标签或强度等值面得到的表面几何，适合剖切、旋转和展示；受阈值、spacing、平滑和简化影响。

可先从最终标签计算对象体积：体素数 × dx × dy × dz，结果单位为 µm³。密度的分母使用可分析组织的实际物理体积，并记录排除区域。坐标、距离和邻接计算统一在同一物理坐标系；明确使用质心距离、表面最短距离还是预定义半径内邻居数。

使用 [vedo 官方示例与文档](https://github.com/marcomusy/vedo)生成等值面、切面和科研图，保存相机、色标、透明度、裁剪范围及尺度。测量层保留原标签和未做展示加工的几何，展示副本才允许简化或平滑；不能用补洞后的外观替代真实缺失数据。若测量网格体积，应检查封闭性与几何有效性。

## 肿瘤细胞与微环境研究示例

假设输入为多通道三维组织：核染色、经实验验证的肿瘤相关标记、免疫表型标记，以及血管或组织边界标注；另有样本 ID、实验分组与生物学重复。这里是分析方案，不表示页面已经识别真实样本。

1. 以核或细胞实例为统计对象，分割与表型判定分开；保留无法可靠判定的对象类别。
2. 在统一坐标系记录肿瘤区域、免疫对象、血管与边界；复核拥挤区、弱信号区和组织边缘。
3. 计算细胞密度、形态、到血管/边界距离以及不同表型间的邻近分布；注明参数、邻接定义和截断边界处理。
4. 以样本/供体或真正的实验重复比较组间差异，避免把同一样本内每个细胞当成独立生物学重复。考虑深度衰减、组织密度、区域选择和检测偏差。
5. 把空间结果作为后续实验的候选假设。**邻近、共现或相关不等于直接相互作用，更不等于机制因果**；机制或药物反应结论还需独立验证与相应实验设计。

## 步骤 7：保存可复现证据包

每次运行保存一个 `run_id`，记录原始与派生版本的关系。最小记录建议为：

| 类别 | 记录字段 |
|---|---|
| 数据 | sample ID、实验分组、原始文件列表与校验和、格式、axes、shape、dtype、spacing、units、channel 名称、缺失层/排除区域。 |
| 处理 | 输入版本、输出版本、工具版本或 Git commit、模型/权重来源及摘要、参数、随机种子、配准变换、PSF 文件与条件、重采样方法。 |
| 人工复核 | ROI 的物理范围、参考标签版本、复核者、时间、对象 ID 修改记录、QC 指标、失败模式与通过/待复核状态。 |
| 定量与展示 | 标签版本、对象 ID 映射、测量公式及单位、邻接定义、边界规则、展示网格加工参数、相机与色标。 |
| 交付 | 原始与派生数据索引、标签、对象表、参数文件、环境记录、QC 报告、切片证据、科研图及来源/许可记录。 |

升级模型或修改参数后生成新运行版本，不覆盖旧标签；对关键 ROI 做前后差异检查。文件存在不等于运行成功，需重读输出并核对记录。浏览器导出的配置只能作为这些外部执行步骤的规划输入，直到实际运行及验证完成前，状态应保留为“未执行 / 演示 / 待验证”。
